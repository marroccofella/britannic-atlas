PROJECT GUIDE · LOCAL SETUP

Britannic Atlas

A guide to the British-world reference project and its separate, Manx-first Mannin companion.

This GitHub Page explains the repository and how to run it. The full atlas needs a server; it does not run inside this static guide. The web application identifies itself as Britannica Atlas in parts of its interface.

Read the setup guideExplore the atlas source

What the repository contains

  • A React reference application covering the United Kingdom, Crown Dependencies, Overseas Territories and connected histories.
  • Source-linked knowledge records, review dates, permanent article routes and discovery feeds.
  • A separate local Mannin answer engine focused on the Isle of Man.

Sources and review dates help you assess an answer. They do not guarantee that every statement is accurate or current. Check the cited primary material before relying on it.

Run the atlas locally

The project requires Node.js 22.13 or newer and npm. After cloning the repository, open its folder in a terminal:

npm ci
npm run dev

Open the local address printed by the development server. The repository uses vinext and Cloudflare tooling; consult its current README before choosing a deployment target.

Mannin is a separate local companion

Mannin runs locally and uses existing account sessions for Claude and MOMM reviews. Answer generation can contact those providers; the repository describes local storage and retrieval separately.

Current status: supervised internal alpha. The repository does not describe it as ready for public, unsupervised use. Additional runtime, model and account setup is required.
